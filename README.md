# Cyber Reference 🔐

A beginner-friendly cybersecurity command reference website built with **HTML, CSS, and vanilla JavaScript**, with help from GitHub Copilot.

Cyber Reference helps users explore common Linux and networking commands, understand what they do, and copy example commands for learning and reference.

## ✨ Features

- **Search commands** by name, category, or description.
- **Category filters** to browse commands by topic.
- **Command explanations** with examples for easier learning.
- **Copy to clipboard** with visible feedback.
- **Responsive design** for desktop and mobile screens.
- **Dark cybersecurity-themed UI** with green accents.
- **No external APIs or libraries required.**

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Copilot for AI-assisted development

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your GitHub repository URL.

### 2. Open the project

Open the project folder in VS Code.

### 3. Run the website

Open `index.html` directly in your browser.

Alternatively, use the **Live Server** extension in VS Code if you have it installed.

## 🎯 Project Goals

This project was created as a hands-on exercise in building a simple application with an AI coding assistant. It demonstrates how GitHub Copilot can help with generating code, implementing interactive features, and developing a user-friendly interface.

## 🔒 Safety Notice

This website is an educational reference tool. Always understand a command before executing it, and only run commands on systems you own or are authorized to use. Examples are provided for learning and should be reviewed before use.
